# Argon 下载校验兼容记录

## 两次设备证据

- GL-BE6500：IPK 下载成功，gzip -t 成功，但没有 od。原检查依赖 od，导致有效包被拒绝。
- GL-VB7200BE：OpenWrt 25.12-SNAPSHOT 使用 APK，没有 od，有 hexdump；直连下载成功，包头为 41444264。此前 gzip 优先修复没有覆盖 ADB 格式。
- VB7200BE 的 GH01 SSL 超时与包格式识别是两个问题，不能合并诊断。直连单独测试成功也不证明完整安装成功。

## 修复原则

1. 不假设厂商 BusyBox 包含 od、ar 等命令。gzip 包直接 gzip -t；其他格式先尝试 od，再回退 hexdump。
2. 没有可用读取工具时明确记录校验原因，不放行未知包。ADB 仍仅允许 APK 分支；当前头部识别不等于完整性或来源认证。
3. 网络失败记录线路和退出码，避免只用下载失败概括工具缺失、无效响应与网络错误。
4. 包连接等待放宽到 15 秒，元信息保持 4 秒；整轮分别保持 120/12 秒。并行下载、串行安装行为保持。
5. 修复覆盖 gzip/IPK、ADB/APK、工具存在与缺失、损坏及 HTML 分支，避免只修眼前一种格式。

## 验证边界

sh/dash 语法与模拟回归通过不代表 BusyBox 实机安装通过。gzip IPK 已有 BE6500 安装成功截图；此次 ADB 修复仍需 VB7200BE 完整安装验证。
